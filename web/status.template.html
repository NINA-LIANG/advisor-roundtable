怎麼更新

  • 自動：每個交易日台灣時間 18:30 抓證交所、櫃買中心、央行資料，檢查通過才發佈。證交所公告的休市日（國定假日等）自動跳過。
  • 手動立即更新：到 GitHub Actions 的 daily-update，按「Run workflow」，可以選只更新某一份資料。手機 GitHub App 也能按。
  • 改內容：理專背景、名詞、內行筆記在 knowledge/ 資料夾，可以直接在 GitHub 網頁上改，或用 Pages CMS 的表單編輯。存檔後自動檢查格式，寫錯不會上線。
  • 出問題時：抓取失敗或檢查沒過，會自動在 Issues 開一張單通知；下一次成功會自動關閉。
